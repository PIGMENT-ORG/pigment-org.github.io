AI Prompts Guide Evolution

By PIGMENT Team March 5, 2026 8 min read

"Make it glitchy." "Add more contrast." "Give it an organic feel." With PIGMENT v6, you can guide evolution using natural language — and watch as your words transform into actual mutations.

The Challenge: From Words to Mutations

Evolution is a blind process — it doesn't understand "glitchy" or "organic." It only understands mutations and fitness. So how do we bridge the gap between human language and genetic algorithms?

The answer is a two-layer system:

  1. Claude API (when available) — Translates prompts into structured mutation plans
  2. Keyword fallback — Intelligent local matching when Claude is unavailable

How Claude Transforms Prompts

When you send a prompt to the /v1/prompt endpoint, the system (if configured with an ANTHROPIC_API_KEY) sends your request to Claude along with the current genome context:

{
  "polygon_count": 150,
  "mean_rgb": [128, 92, 156],
  "fitness": 72.4,
  "style": "custom",
  "generation": 1542,
  "prompt": "make it glitchy with neon accents"
}

Claude returns a structured mutation plan:

{
  "intent": "Apply digital glitch aesthetic with neon highlights",
  "operations": [
    {"op": "glitch_colors", "intensity": 0.8},
    {"op": "chaos", "intensity": 0.4, "params": {"fraction": 0.2}},
    {"op": "saturate", "intensity": 0.9, "params": {"amount": 0.7}},
    {"op": "boost_contrast", "intensity": 0.6}
  ],
  "mutation_rate_multiplier": 2.5
}

This plan is then executed on the artwork, applying the specified mutations with the given intensities.

Complete Example

Here's a real prompt sequence:

// Initial work
const work = await createWork("Base Portrait");

// Apply glitch effect
const glitch = await applyPrompt(work.id, "make it glitchy");
// → glitch_colors, chaos, boost_contrast
// Fitness: 72.4% → 68.9% (sometimes glitch reduces fitness!)

// Then add contrast
const contrast = await applyPrompt(glitch.child_id, "more contrast, make it pop");
// → boost_contrast, saturate
// Fitness: 68.9% → 74.2%

// Finally, smooth it out
const smooth = await applyPrompt(contrast.child_id, "smooth the harsh edges");
// → smooth, organic_spread
// Fitness: 74.2% → 76.8%

Learning from Prompts

Every prompt is logged in the prompt_logs table:

SELECT prompt, intent, operations_applied 
FROM prompt_logs 
WHERE used_claude = true 
ORDER BY created_at DESC 
LIMIT 5;

This data can be used to:

  • Improve keyword matching over time
  • Train custom models for prompt interpretation
  • Understand what users want most often

Best Practices

  • Be specific: "add magenta channel offset" works better than "make it glitchy"
  • Combine styles: "glitchy but organic" will try to balance both
  • Use contrast terms: "more contrast", "brighter", "darker" adjust luminance
  • Reference colors: "neon green", "warm orange" shift the palette
  • Iterate: Apply prompts incrementally for finer control
