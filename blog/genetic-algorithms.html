How Genetic Algorithms Create Art

By PIGMENT Team March 15, 2026 12 min read
🧬 → 🎨
Evolution in action: random polygons → structured art

Genetic algorithms mimic natural selection to "evolve" solutions to problems. In PIGMENT, we use them to evolve artwork — starting from random polygons and progressively refining them toward a target image or aesthetic goal.

The Core Concepts

Every genetic algorithm has five fundamental components:

  • Population — A set of candidate solutions (in our case, a collection of polygons)
  • Genome — The "DNA" of each solution (polygon positions, colors, opacities)
  • Fitness function — Measures how good each solution is (similarity to target image)
  • Selection — Choosing the best solutions to reproduce
  • Mutation — Random changes to create new variations

How PIGMENT Represents Art

In PIGMENT, every artwork is stored as a .pg (PIGMENT Genome) file. Think of it as the DNA of your art:

-- PIGMENT Genome v6.0.0
-- @fitness 78.5
-- @generation 1542

canvas { width: 400 height: 400 }

palette {
  c0: #ff3366
  c1: #33ff99
  c2: #3366ff
}

layer evolved {
  zone poly_0 {
    color: palette.c0
    opacity: 0.8
    points: 120,140 180,120 160,200
  }
  zone poly_1 {
    color: palette.c1
    opacity: 0.5
    points: 220,180 280,220 240,280
  }
}

Each polygon has:

  • Points — Coordinates that define its shape
  • Color — RGB values from the palette
  • Opacity — Transparency level (0-255)

The Evolution Process

1. Initialization

When you load an image, PIGMENT creates a population of random polygons. In your frontend code:

function randPoly() {
  const w = state.targetW, h = state.targetH;
  const size = 10 + Math.random() * Math.min(w, h) * 0.35;
  const cx = Math.random() * w, cy = Math.random() * h;
  const sides = 3 + Math.floor(Math.random() * 3);
  const pts = [];
  
  for (let i = 0; i < sides; i++) {
    const a = (i / sides) * Math.PI * 2 + Math.random() * 0.8;
    const r = size * (0.4 + Math.random() * 0.9);
    pts.push([cx + Math.cos(a) * r, cy + Math.sin(a) * r]);
  }
  
  return {
    pts,
    r: Math.random() * 255,
    g: Math.random() * 255,
    b: Math.random() * 255,
    a: 20 + Math.random() * 160
  };
}

At this stage, the artwork looks like random colored blobs — but that's exactly what we want. Evolution needs diversity to explore the solution space.

2. Fitness Calculation

The fitness function measures how close the current polygons are to the target image:

function calcFitness(polys) {
  // Render polygons to canvas
  renderPolygons(ctx, polys);
  const evolved = ctx.getImageData(0, 0, w, h).data;
  
  // Compare pixel by pixel with target
  let diff = 0;
  for (let i = 0; i < evolved.length; i += 16) {
    const dr = evolved[i] - target[i];
    const dg = evolved[i+1] - target[i+1];
    const db = evolved[i+2] - target[i+2];
    diff += dr*dr + dg*dg + db*db;
  }
  
  // Convert to percentage (100% = perfect match)
  const maxDiff = 3 * 255 * 255 * (evolved.length / 16);
  return 100 * (1 - diff / maxDiff);
}

This is the "survival of the fittest" mechanism — polygons that make the image look more like the target are considered better.

3. Mutation Operators

PIGMENT v6 includes 7 mutation operators, each affecting the genome differently:

Operator Description Effect
scale Resize polygon Changes shape size while preserving proportions
translate Move polygon Shifts position in x/y direction
color Shift RGB values Changes color slightly
opacity Change transparency Adjusts how much background shows through
rotate Rotate around center Spins the polygon
addpoint Add vertex Increases complexity (max 8 points)
intelligent Use best operator Selects operator with highest success rate

4. Adaptive Probabilities

One of PIGMENT's most powerful features is its adaptive operator selection. Each operator tracks its success rate:

const OPS = [
  { name: 'Scale', key: 'scale', attempts: 0, successes: 0 },
  { name: 'Translate', key: 'translate', attempts: 0, successes: 0 },
  // ...
];

When an operator improves fitness, its probability increases slightly. When it fails, probability decreases. Over time, the system learns which operators work best for the current image and phase.

5. Multi-Phase Strategy

PIGMENT uses different strategies depending on fitness level:

const weights = {
  explore: { scale:0.35, translate:0.25, color:0.20, opacity:0.10, rotate:0.07, intelligent:0.03 },
  refine:  { scale:0.30, translate:0.15, color:0.20, opacity:0.20, rotate:0.10, intelligent:0.05 },
  polish:  { scale:0.25, translate:0.15, color:0.20, opacity:0.20, rotate:0.12, intelligent:0.08 }
};

Explore phase (0-30% fitness): Large mutations to discover structure
Refine phase (30-60%): Moderate adjustments to improve
Polish phase (60-100%): Fine-tuning for final accuracy

Stagnation Detection

Sometimes evolution gets stuck in local optima — good but not great solutions. PIGMENT detects stagnation (no improvement for 400+ generations) and activates special "breaker" strategies:

  • Shake: Large random movements to escape local minima
  • Recolor: Mass color randomization to find new color basins
  • Reshape: Aggressive polygon reshaping

The 16D Feature Vector

Beyond pixel-by-pixel comparison, PIGMENT extracts a 16-dimensional feature vector from every genome:

[
  r_mean, g_mean, b_mean,      # Average colors
  r_std, g_std, b_std,          # Color variance
  lum_contrast,                 # Brightness spread
  color_entropy,                # Color complexity
  poly_count,                   # Normalized polygon count
  avg_opacity,                  # Average transparency
  avg_points,                   # Average points per polygon
  hue_spread,                   # Color diversity
  glitch_factor,                # Channel imbalance
  organic_factor,               # Green bias
  void_factor,                  # Darkness
  fitness_proxy                 # Normalized fitness
]

This vector enables the kinship system and similarity search, allowing you to find related artworks even if they evolved from different starting points.

Real-World Example

Here's what happens in a typical evolution session:

Generation 0: Fitness 12.4% - Random colored blobs
Generation 100: Fitness 34.7% - Basic shapes emerging
Generation 500: Fitness 67.2% - Structure becoming clear
Generation 1000: Fitness 84.9% - Fine details appearing
Generation 2000: Fitness 92.3% - Near-perfect match

Each generation applies hundreds of mutations, with successful ones being kept and unsuccessful ones discarded. The system gets smarter over time, learning which operators work best for each context.
