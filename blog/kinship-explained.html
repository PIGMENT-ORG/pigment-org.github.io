Kinship Explained: Art Family Trees

By PIGMENT Team March 10, 2026 10 min read

Just as you can trace your family tree, PIGMENT lets you trace the ancestry of your artworks. Parents, children, siblings, cousins — every evolved artwork has a lineage, and our kinship system reveals these connections.

What is Kinship?

In PIGMENT, every time you evolve an artwork, you create a parent-child relationship. The original work is the parent, and the evolved result is its child. Over many generations, these relationships form complex family trees.

But kinship goes beyond direct lineage. Two artworks might be:

  • Siblings — Share the same parent
  • Cousins — Share grandparents or great-grandparents
  • Similar — Visually related but not directly connected

The 16-Dimensional Feature Vector

The foundation of kinship is the feature vector — a mathematical fingerprint of each artwork. When you create or evolve a work, PIGMENT extracts 16 perceptual features:

0-2: RGB meansAverage color values
3-5: RGB standard deviationsColor variance
6: Luminance contrastBrightness spread
7: Color entropyColor complexity
8: Polygon countNormalized (0-1)
9: Average opacityTransparency level
10: Average points per polygonShape complexity
11: Hue spreadColor diversity
12: Glitch factorChannel imbalance
13: Organic factorGreen bias + smoothness
14: Void factorDarkness + low complexity
15: Fitness proxyNormalized fitness

These features capture both visual appearance (colors, contrast) and structural properties (polygon counts, complexity).

How Similarity is Calculated

Kinship uses a weighted combination of three similarity measures:

40%
Visual
RGB means, entropy, contrast
30%
Generational
Parent/child distance
30%
Structural
Polygon count, opacity

The combined score determines the relationship:

  • Parent/Child ≥ 90% — Direct lineage (determined by parent_id)
  • Sibling ≥ 82% — Same parent
  • Cousin 65-81% — Share grandparents
  • Similar 45-64% — Visually related

Ancestry Tracking

The /v1/ancestry/{id} endpoint reveals an artwork's complete lineage:

GET /v1/ancestry/work_abc123

{
  "work_id": "work_abc123",
  "title": "Abstract Study #1",
  "generation": 42,
  "fitness": 78.5,
  "lineage": [
    {
      "id": "work_xyz789",
      "title": "Base Image",
      "fitness": 100.0,
      "generation": 0
    },
    {
      "id": "work_def456",
      "title": "Base Image (gen 1)",
      "fitness": 45.2,
      "generation": 1
    }
  ],
  "fitness_history": [
    {"generation": 0, "fitness": 100.0, "operator": "init"},
    {"generation": 1, "fitness": 45.2, "operator": "scale"},
    {"generation": 42, "fitness": 78.5, "operator": "rotate"}
  ]
}

This reveals not just who the ancestors are, but how fitness evolved over time and which operators were most effective at each stage.

Finding Similar Works

The /v1/search/similar endpoint lets you find relatives even without a direct parent link:

POST /v1/search/similar
{
  "work_id": "work_abc123",
  "limit": 10
}

This uses FAISS-powered similarity search (in Layer 4) to find the nearest neighbors in feature space, returning results in milliseconds even with thousands of works.

Visualizing Kinship

We provide an official visualization library to make kinship trees interactive:

<script src="https://pigment-org.github.io/js/kinship-viz.js"></script>
<div id="family-tree" style="width:100%; height:400px;"></div>

const data = await fetch('https://pigment-api.onrender.com/v1/kinship', {
    method: 'POST',
    headers: { 'X-API-Key': 'your-key' },
    body: JSON.stringify({ work_id: 'work_abc123' })
});

KinshipViz.render('family-tree', data);

The visualization shows:

  • Node size — Importance/influence of each work
  • Edge thickness — Similarity strength
  • Colors — Different relationship types
  • Tooltips — Hover for fitness, generation, similarity

Let's trace a real artwork's family:

{

  "parents": [{

    "title": "Original Photo",

  }],
  "siblings": [{
    "id": "work_glitch_41",
    "title": "Glitch Portrait (gen 41)",
    "similarity": 87.6,
    "relationship": "sibling"
  }],
  "children": [{
    "id": "work_glitch_43",
    "title": "Glitch Portrait (gen 43)",
    "similarity": 94.3,
    "relationship": "child"
  }],
  "cousins": [...],
  "similar": [...]
}

This tells us:

  • The artwork evolved from an original photo
  • It has a sibling from the previous generation
  • It spawned a child that's 94.3% similar
  • There are more distant relatives in the "cousins" and "similar" lists

Why Kinship Matters

Kinship isn't just a curiosity — it's a powerful tool for:

  • Tracking influence — See which artworks inspired others
  • Finding originals — Trace back to source images
  • Discovering clusters — Find all works in a particular style
  • Analyzing evolution — Study how fitness improves over generations

The next time you evolve an artwork in PIGMENT, remember: you're not just creating a single image — you're starting a new branch in the vast family tree of algorithmic art.
