Introduction

PIGMENT is a REST API for evolutionary art generation. Drop any image and watch it evolve through generations of mutations — driven by genetic algorithms, edge-aware fitness scoring, and an optional AI prompt layer powered by Claude.

Base URL https://pigment-api.onrender.com
Note The API is hosted on Render's free tier and may take 30–60 seconds to respond on the first request after a period of inactivity (cold start). Subsequent requests are fast.

API Overview

All endpoints accept and return JSON. Authentication is via an X-API-Key header. The API follows standard REST conventions.

All Endpoints

  • POST/v1/works — Create a new artwork
  • GET/v1/works/:id — Get artwork metadata
  • POST/v1/evolve — Start an evolution job
  • GET/v1/evolve/:job_id — Get job status
  • GET/v1/kinship/:id — Get artwork relatives
  • POST/v1/prompt — Translate AI prompt to mutations
  • GET/v1/gallery — Browse public artworks
  • POST/v1/users — Create account & get API key

Genome Format (.pg)

PIGMENT uses a custom genome format called .pg (Pigment Genome) to represent artwork as editable text. A genome describes a canvas, palette, and one or more polygon layers.

-- PIGMENT Genome v6.0.0
-- @fitness 0.94
-- @generations 1500

canvas { width: 400 height: 400 background: #0a0a0a }

palette {
  color_0: #c8ff00
  color_1: #ff3b2f
}

layer base {
  zone poly_0 {
    color: palette.color_0
    opacity: 0.85
    points: 120,140 180,120 160,200
  }
  zone poly_1 {
    color: palette.color_1
    opacity: 0.6
    points: 200,100 260,140 240,220 180,200
  }
}

Fitness Scoring

PIGMENT measures how closely an evolved image matches the target using a weighted combination of edge similarity and color similarity:

Formula fitness = (edge_similarity × 0.70) + (color_similarity × 0.30)

Edge similarity is computed using Sobel operators on both images. Color similarity compares RGB histograms. A fitness of 1.0 is a perfect match; most high-quality evolutions achieve 0.85–0.98 after thousands of generations.
