Introduction to PIGMENT

PIGMENT is a powerful API that uses genetic algorithms to generate unique artwork. Watch images evolve through generations of mutation and selection.

✨ New in v6: AI-powered evolution, kinship tracking, and real-time WebSocket support.

How it works

PIGMENT represents images as collections of colored polygons. Through genetic algorithms, these polygons evolve to match target images or create entirely new artwork based on prompts.

🧬 Evolution

Start with random polygons and evolve toward your target image. Fine-tune mutation rates, polygon counts, and more.

Learn more →

🔗 Kinship

Track relationships between artworks. See how they influence each other and build family trees of artistic evolution.

Learn more →

🤖 AI Prompts

Describe what you want to see, and our AI will guide the evolution process. "Make it glitchy" or "Add more contrast".

Learn more →

Quick Start

Get started in minutes with our JavaScript client:

import { PigmentClient } from 'pigment-api';

const client = new PigmentClient({
    apiKey: 'your-api-key'
});

const result = await client.evolve({
    target_url: 'https://example.com/image.jpg',
    generations: 1000
});

console.log(`Fitness: ${result.fitness}%`);
