PIGMENT v6 API Documentation

Build AI-powered art applications with genetic algorithms.

Base URL

https://pigment-api.onrender.com

Overview

PIGMENT is a genetic algorithm platform that evolves images through mutations. Every artwork is represented as a genome — a collection of colored polygons with opacity and position data.

The API provides endpoints for:

  • Creating and managing artworks
  • Evolving works through genetic algorithms
  • Tracking kinship relationships between works
  • Applying AI prompts via Claude
  • Searching similar works by feature vectors

Feature Vectors

Each artwork has a 16-dimensional perceptual feature vector:

[
  r_mean, g_mean, b_mean,      # 0-2: Average RGB
  r_std, g_std, b_std,          # 3-5: RGB standard deviations
  lum_contrast,                 # 6: Luminance spread
  color_entropy,                # 7: Color complexity
  poly_count,                   # 8: Normalized polygon count
  avg_opacity,                  # 9: Average opacity
  avg_points,                   # 10: Average points per polygon
  hue_spread,                   # 11: Color diversity
  glitch_factor,                # 12: Channel imbalance
  organic_factor,               # 13: Green bias + smoothness
  void_factor,                  # 14: Darkness + low complexity
  fitness_proxy                  # 15: Normalized fitness
]

Quick Example

JavaScript Python cURL 
// Create a user (get API key)
const user = await fetch('https://pigment-api.onrender.com/v1/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'me@example.com' })
}).then(r => r.json());

// Your API key is in user.api_key

// Create an artwork
const work = await fetch('https://pigment-api.onrender.com/v1/works', {
  method: 'POST',
  headers: { 
    'Content-Type': 'application/json',
    'X-API-Key': user.api_key
  },
  body: JSON.stringify({
    title: 'My First Art',
    content: '-- PIGMENT Genome...',
    tags: ['demo']
  })
}).then(r => r.json());

// Evolve it
const evolved = await fetch('https://pigment-api.onrender.com/v1/evolve', {
  method: 'POST',
  headers: { 'X-API-Key': user.api_key },
  body: JSON.stringify({ work_id: work.id, steps: 500 })
}).then(r => r.json());
