Getting Started in 5 Minutes

1. Get Your API Key

Every request needs an API key. Create one with your email:

curl -X POST https://pigment-api.onrender.com/v1/users \
  -H "Content-Type: application/json" \
  -d '{"email": "your@email.com"}'

Response:

{
  "id": "user_abc123",
  "email": "your@email.com",
  "api_key": "pigment_xyz789...",
  "plan": "free"
}

2. Create Your First Artwork

Artworks are stored as .pg genome files. Here's a minimal example:

-- @fitness 0.0
-- @generation 0

canvas {
  width: 400
  height: 400
}

palette {
  color_0: #ff3366
}

layer base {
  zone poly_0 {
    color: palette.color_0
    opacity: 0.8
    points: 120,140 180,120 160,200
  }
}

Upload it:

curl -X POST https://pigment-api.onrender.com/v1/works \
  -H "X-API-Key: pigment_xyz789..." \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My First Triangle",
    "content": "-- @fitness 0.0...",
    "tags": ["demo", "triangle"]
  }'

3. Evolve It

Run 500 generations of evolution:

curl -X POST https://pigment-api.onrender.com/v1/evolve \
  -H "X-API-Key: pigment_xyz789..." \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "abc123",
    "steps": 500
  }'

Response includes the new child work:

{
  "parent_id": "abc123",
  "child_id": "def456",
  "fitness_before": 12.4,
  "fitness_after": 38.7,
  "improvement": 26.3,
  "operator": "scale"
}

4. Check Kinship

See how your works are related:

curl -X POST https://pigment-api.onrender.com/v1/kinship \
  -H "X-API-Key: pigment_xyz789..." \
  -H "Content-Type: application/json" \
  -d '{"work_id": "def456"}'
POST /v1/kinship

Returns parents, children, siblings, and similar works with similarity scores.

5. Try the AI Prompt

Use natural language to guide evolution:

curl -X POST https://pigment-api.onrender.com/v1/prompt \
  -H "X-API-Key: pigment_xyz789..." \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "def456",
    "prompt": "make it glitchy, more contrast"
  }'

Claude (or local fallback) returns a mutation plan:

{
  "intent": "Apply digital glitch aesthetic",
  "operations_applied": ["glitch_colors", "chaos", "boost_contrast"],
  "used_claude": true
}
