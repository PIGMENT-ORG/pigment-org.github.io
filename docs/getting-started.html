Quick Start Guide

Get up and running with PIGMENT v6 in under 5 minutes. Follow these steps to create an account, upload your first artwork, and start an evolution job.

Base URL All API requests go to https://pigment-api.onrender.com. The server may take up to 60 seconds on the first request after inactivity (cold start).

1Get Your API Key

Create an account with a single API call. No password needed — authentication is entirely key-based.

const user = await res.json();
console.log(user.api_key); // save this!

Save your API key Your API key is shown only once. Store it securely — treat it like a password. The interactive tool above saves keys locally in your browser.

2Create Your First Artwork

Upload a .pg genome file to register an artwork. You can start with the minimal template below.

3Start an Evolution Job

Submit your artwork for evolution. The API queues a background job and returns a job_id you can poll for progress.

4Poll for Progress

Check job status until status is "complete". Typical runs converge in 30–120 seconds depending on complexity.
