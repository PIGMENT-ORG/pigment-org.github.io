Quick Start Guide

Get up and running with PIGMENT in less than 5 minutes. Follow these steps to make your first API call.

✨ New to PIGMENT? This guide will walk you through everything you need to know to start using our API.
1

Get Your API Key

First, you'll need an API key to authenticate your requests. Sign up for a free account and generate your first API key.

Generate API Key 
# Sign up at https://pigment.dev
# Navigate to Dashboard → API Keys
# Click "Generate New Key"
# Copy your key (starts with pk_live_ or pk_test_)

You'll get a key that looks like: pk_live_abc123def456ghi789jkl0mno

⚠️ Important: Never share your API key or commit it to version control. Use environment variables instead.
2

Install the Client

Choose your preferred programming language and install the official PIGMENT client.

Install with npm 
npm install pigment-api
Install with pip 
pip install pigment-api
Install with yarn 
yarn add pigment-api

If you prefer to use the REST API directly, you can skip this step and use cURL or any HTTP client.

3

Set Up Environment Variables

Store your API key securely using environment variables.

.env file 
PIGMENT_API_KEY=pk_live_abc123def456ghi789jkl0mno
PIGMENT_API_URL=https://api.pigment.dev/v1

Make sure to add .env to your .gitignore file to keep your keys secure.

4

Make Your First Request

Now let's evolve an image! Here's a complete example in multiple languages:

JavaScript (Node.js) 
import { PigmentClient } from 'pigment-api';

// Initialize the client
const client = new PigmentClient({
    apiKey: process.env.PIGMENT_API_KEY
});

async function evolveImage() {
    try {
        // Start evolution
        const job = await client.evolve({
            target_url: 'https://images.unsplash.com/photo-1500462918059-b1a0cb512f1d',
            generations: 1000,
            polygons: 100,
            mutation_rate: 0.1
        });

        console.log('Evolution started:', job.id);
        console.log('Estimated time:', job.estimated_seconds, 'seconds');

        // Poll for results
        let status;
        do {
            await new Promise(r => setTimeout(r, 1000));
            status = await client.getJobStatus(job.id);
            console.log(`Progress: ${status.progress}% | Fitness: ${status.fitness}%`);
        } while (status.status === 'processing');

        if (status.status === 'completed') {
            console.log('Evolution complete!');
            console.log('Result URL:', status.result.image_url);
            console.log('Final fitness:', status.result.fitness, '%');
        }

    } catch (error) {
        console.error('Error:', error.message);
    }
}

evolveImage();
Python 
import os
import time
from pigment import PigmentClient

# Initialize the client
client = PigmentClient(
    api_key=os.environ.get('PIGMENT_API_KEY')
)

def evolve_image():
    try:
        # Start evolution
        job = client.evolve(
            target_url='https://images.unsplash.com/photo-1500462918059-b1a0cb512f1d',
            generations=1000,
            polygons=100,
            mutation_rate=0.1
        )

        print(f'Evolution started: {job.id}')
        print(f'Estimated time: {job.estimated_seconds} seconds')

        # Poll for results
        while True:
            time.sleep(1)
            status = client.get_job_status(job.id)
            print(f'Progress: {status.progress}% | Fitness: {status.fitness}%')

            if status.status != 'processing':
                break

        if status.status == 'completed':
            print('Evolution complete!')
            print(f'Result URL: {status.result.image_url}')
            print(f'Final fitness: {status.result.fitness}%')

    except Exception as e:
        print(f'Error: {e}')

if __name__ == '__main__':
    evolve_image()
cURL 
# Start evolution job
curl -X POST https://api.pigment.dev/v1/evolve \
  -H "Authorization: Bearer $PIGMENT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "target_url": "https://images.unsplash.com/photo-1500462918059-b1a0cb512f1d",
    "generations": 1000,
    "polygons": 100,
    "mutation_rate": 0.1
  }'

# Response:
# {
#   "job_id": "job_123456",
#   "estimated_seconds": 45,
#   "status": "processing"
# }

# Check status
curl -X GET https://api.pigment.dev/v1/jobs/job_123456 \
  -H "Authorization: Bearer $PIGMENT_API_KEY"

# Response when complete:
# {
#   "status": "completed",
#   "progress": 100,
#   "result": {
#     "image_url": "https://storage.pigment.dev/result_123456.png",
#     "fitness": 98.5,
#     "generations": 1000
#   }
# }
5

Understanding the Response

When your evolution completes, you'll receive a response with these fields:

Field Type Description
image_url string URL to download the generated image
fitness float Final fitness score (0-100%)
generations integer Number of generations completed
polygons integer Number of polygons used
duration_ms integer Total processing time in milliseconds

Common Issues

Issue Solution
401 Unauthorized Check that your API key is correct and properly formatted in the Authorization header
429 Too Many Requests You've hit the rate limit. Implement exponential backoff or upgrade your plan
400 Invalid Image Ensure your image URL is publicly accessible and in a supported format (JPEG, PNG, WebP)
Job stuck at 0% Check that your image URL is accessible. Some URLs expire or require authentication
