Quick Start Guide

Get up and running with PIGMENT v6 in under 5 minutes. Follow these steps to create an account, upload your first artwork, and start an evolution job.

Base URL All API requests go to https://pigment-api.onrender.com. The server may take up to 60 seconds on the first request after inactivity (cold start).

1Create an Account & Get Your API Key

Create an account with a single API call. No password needed — authentication is entirely key-based.

POST /v1/users 
curl -X POST https://pigment-api.onrender.com/v1/users \
  -H "Content-Type: application/json" \
  -d '{"email": "you@example.com"}'
const res = await fetch('https://pigment-api.onrender.com/v1/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'you@example.com' })
});
const user = await res.json();
console.log(user.api_key); // save this!
import requests

res = requests.post(
    'https://pigment-api.onrender.com/v1/users',
    json={'email': 'you@example.com'}
)
user = res.json()
print(user['api_key'])  # save this!

Save your API key Your API key is shown only once. Store it securely — treat it like a password. If lost, use POST /v1/users/rotate-key to generate a new one.

2Create Your First Artwork

Upload a .pg genome file to register an artwork. You can start with the minimal template below.

POST /v1/works 
curl -X POST https://pigment-api.onrender.com/v1/works \
  -H "X-API-Key: pigment_a1b2c3d4..." \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My First Artwork",
    "content": "-- PIGMENT Genome v6.0.0\n-- @fitness 0.0\n\ncanvas { width: 400 height: 400 background: #0a0a0a }\n\npalette { color_0: #c8ff00 }\n\nlayer base {\n  zone poly_0 {\n    color: palette.color_0\n    opacity: 0.8\n    points: 120,140 180,120 160,200\n  }\n}",
    "tags": ["demo", "triangle"]
  }'
const genome = `-- PIGMENT Genome v6.0.0
-- @fitness 0.0

canvas { width: 400 height: 400 background: #0a0a0a }

palette { color_0: #c8ff00 }

layer base {
  zone poly_0 {
    color: palette.color_0
    opacity: 0.8
    points: 120,140 180,120 160,200
  }
}`;

const res = await fetch('https://pigment-api.onrender.com/v1/works', {
  method: 'POST',
  headers: {
    'X-API-Key': 'pigment_a1b2c3d4...',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    title: 'My First Artwork',
    content: genome,
    tags: ['demo', 'triangle']
  })
});
const work = await res.json();
console.log(work.id); // wk_2a7f8c3e1b9d4f6

3Start an Evolution Job

Submit your artwork for evolution. The API queues a background job and returns a job_id you can poll for progress.

POST /v1/evolve 
curl -X POST https://pigment-api.onrender.com/v1/evolve \
  -H "X-API-Key: pigment_a1b2c3d4..." \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "wk_2a7f8c3e1b9d4f6",
    "generations": 1000,
    "operators": ["color", "opacity", "scale", "rotate"],
    "prompt": "make it glitchy and neon"
  }'
Response 200 OK 
{
  "job_id": "job_x9z3k1m2",
  "work_id": "wk_2a7f8c3e1b9d4f6",
  "status": "queued",
  "generations": 1000,
  "fitness": 0.0,
  "eta_seconds": 45
}

4Poll for Progress

Check job status until status is "complete". Typical runs converge in 30–120 seconds depending on complexity.

curl https://pigment-api.onrender.com/v1/evolve/job_x9z3k1m2 \
  -H "X-API-Key: pigment_a1b2c3d4..."
async function waitForJob(jobId, apiKey) {
  while (true) {
    const res = await fetch(
      `https://pigment-api.onrender.com/v1/evolve/${jobId}`,
      { headers: { 'X-API-Key': apiKey } }
    );
    const job = await res.json();
    console.log(`Fitness: ${job.fitness} | Gen: ${job.generation}`);
    if (job.status === 'complete' || job.status === 'failed') {
      return job;
    }
    await new Promise(r => setTimeout(r, 2000));
  }
}

const result = await waitForJob('job_x9z3k1m2', 'pigment_a1b2c3d4...');
