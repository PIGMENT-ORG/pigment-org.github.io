Changelog

All notable changes to the PIGMENT v6 API.

v6.1.0 March 2026

FEATURE NEW ENDPOINT

  • Added /v1/prompt endpoint for AI-guided evolution
  • Introduced 8 new mutation operators for richer evolution
  • Kinship system now includes "cousin" relationships
  • WebSocket support for real-time evolution progress

v6.0.0 February 2026

MAJOR RELEASE

  • Complete rewrite with pure Python stdlib backend
  • 16-dimensional feature vectors for kinship analysis
  • 6 mutation operators: scale, rotate, color, translate, opacity, intelligent
  • Real-time evolution with adaptive strategies
  • SQLite database with full kinship tracking

v5.3.0 December 2025

FEATURE IMPROVEMENT

  • Improved error messages with request_id tracking
  • Added /v1/search/similar endpoint for finding related works
  • Rate limiting headers now included in all responses
  • Performance optimizations for large works

v5.2.0 October 2025

FEATURE

  • Added /v1/ancestry endpoint for full lineage tracking
  • Style detection now classifies glitch/organic/void
  • Genome editor with .pg file support
  • Training data collection for operator success rates

v5.1.0 August 2025

FIX ENDPOINT

  • Fixed pagination in /v1/works and /v1/gallery
  • Added style filtering to list endpoints
  • Improved JSON validation error messages
  • Documentation updates with examples

v5.0.0 June 2025

INITIAL RELEASE

  • Initial public release of PIGMENT v5
  • Basic evolution endpoints (/v1/works, /v1/evolve)
  • Simple kinship based on cosine similarity
  • SQLite persistence with 5 mutation operators

Upcoming Features

  • Batch evolution for multiple works simultaneously
  • Custom mutation operator plugins
  • FAISS-powered kinship for faster similarity search
  • Export to multiple image formats (SVG, PNG, PDF)
  • User collections and galleries
