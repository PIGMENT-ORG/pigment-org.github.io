Authentication

All API requests require authentication using API keys. This guide explains how to get and use your API keys securely.

⚠️ Important: Never share your API keys or commit them to version control. Use environment variables or secure secret management.

Getting Your API Key

To use the PIGMENT API, you need an API key. Here's how to get one:

  1. Create a free account at pigment.dev
  2. Navigate to your Dashboard → API Keys
  3. Click "Generate New Key"
  4. Copy and securely store your key
Example API Key 
pk_live_abc123def456ghi789jkl0mno

Using Your API Key

Include your API key in all requests using the Authorization header:

Header Format 
Authorization: Bearer YOUR_API_KEY

Example Requests

curl -X POST https://api.pigment.dev/v1/evolve \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "target_url": "https://example.com/image.jpg",
    "generations": 1000
  }'
const response = await fetch('https://api.pigment.dev/v1/evolve', {
    method: 'POST',
    headers: {
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({
        target_url: 'https://example.com/image.jpg',
        generations: 1000
    })
});
import requests

response = requests.post(
    'https://api.pigment.dev/v1/evolve',
    headers={
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    },
    json={
        'target_url': 'https://example.com/image.jpg',
        'generations': 1000
    }
)

API Key Types

PIGMENT provides two types of API keys:

Type Prefix Use Case Rate Limit
Test pk_test_ Development & testing 100 req/min
Live pk_live_ Production applications 1000 req/min

Security Best Practices

✅ Do

  • Use environment variables
  • Rotate keys regularly
  • Use test keys in development
  • Monitor key usage
  • Set up alerts for unusual activity

❌ Don't

  • Hardcode keys in source code
  • Share keys via email/chat
  • Commit keys to git
  • Use live keys in client-side code
  • Ignore security warnings

Environment Variables

Always store your API keys in environment variables:

.env file 
PIGMENT_API_KEY=pk_live_abc123def456ghi789jkl0mno
PIGMENT_API_URL=https://api.pigment.dev/v1

Loading in different languages:

// JavaScript
const apiKey = process.env.PIGMENT_API_KEY;

# Python
import os
api_key = os.getenv('PIGMENT_API_KEY')

// Node.js
const apiKey = process.env.PIGMENT_API_KEY;

// Ruby
api_key = ENV['PIGMENT_API_KEY']

Error Responses

Authentication errors return standard HTTP status codes:

Code Description Resolution
401 Missing or invalid API key Check Authorization header
403 Key doesn't have permission Check key type and scope
429 Rate limit exceeded Reduce request frequency

Managing Keys

You can manage your API keys through the dashboard:

  • View - See all active keys
  • Create - Generate new keys
  • Revoke - Immediately invalidate compromised keys
  • Rename - Give keys descriptive names
  • Usage stats - Monitor key usage
💡 Pro Tip: Create separate keys for development, staging, and production environments. This makes it easier to track usage and revoke access if needed.
