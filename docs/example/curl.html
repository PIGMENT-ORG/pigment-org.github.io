cURL Examples

Command-line examples for all PIGMENT v6 API endpoints.

1. Get an API Key

curl -X POST https://pigment-api.onrender.com/v1/users \
  -H "Content-Type: application/json" \
  -d '{"email": "your-email@example.com"}'

2. Create a Work

curl -X POST https://pigment-api.onrender.com/v1/works \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My First Artwork",
    "content": "-- PIGMENT Genome v6.0.0\n-- @fitness 0.0\n\ncanvas { width: 400 height: 400 }\n\npalette { color_0: #ff3366 }\n\nlayer base {\n  zone poly_0 {\n    color: palette.color_0\n    opacity: 0.8\n    points: 120,140 180,120 160,200\n  }\n}",
    "tags": ["demo", "triangle"]
  }'

3. List Your Works

curl "https://pigment-api.onrender.com/v1/works?limit=10&offset=0" \
  -H "X-API-Key: your-api-key"

4. Get Single Work

curl https://pigment-api.onrender.com/v1/works/work_abc123def456 \
  -H "X-API-Key: your-api-key"

5. Evolve a Work

curl -X POST https://pigment-api.onrender.com/v1/evolve \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_abc123def456",
    "steps": 500,
    "mutation_rate": 1.2
  }'

6. Get Kinship

curl -X POST https://pigment-api.onrender.com/v1/kinship \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"work_id": "work_abc123def456"}'

7. Search Similar Works

curl -X POST https://pigment-api.onrender.com/v1/search/similar \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_abc123def456",
    "limit": 5
  }'

8. Get Ancestry

curl https://pigment-api.onrender.com/v1/ancestry/work_abc123def456 \
  -H "X-API-Key: your-api-key"

9. Apply AI Prompt

curl -X POST https://pigment-api.onrender.com/v1/prompt \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_abc123def456",
    "prompt": "make it glitchy with more contrast"
  }'

10. Browse Gallery

curl "https://pigment-api.onrender.com/v1/gallery?limit=20" \
  -H "X-API-Key: your-api-key"

11. Delete a Work

curl -X DELETE https://pigment-api.onrender.com/v1/works/work_abc123def456 \
  -H "X-API-Key: your-api-key"

12. Check Health (No Auth)

curl https://pigment-api.onrender.com/health
