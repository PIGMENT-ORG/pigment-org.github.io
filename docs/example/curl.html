cURL Examples

Command-line examples for all PIGMENT API endpoints.

Setup

export PIGMENT_API_KEY="pk_live_abc123..."

Start Evolution

curl -X POST https://api.pigment.dev/v1/evolve \
  -H "Authorization: Bearer $PIGMENT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "target_url": "https://example.com/image.jpg",
    "generations": 1000,
    "polygons": 150
  }'

Check Job Status

curl -X GET https://api.pigment.dev/v1/jobs/job_abc123 \
  -H "Authorization: Bearer $PIGMENT_API_KEY"

List Works

curl -X GET "https://api.pigment.dev/v1/works?limit=10&sort=fitness" \
  -H "Authorization: Bearer $PIGMENT_API_KEY"

Get Single Work

curl -X GET https://api.pigment.dev/v1/works/work_123 \
  -H "Authorization: Bearer $PIGMENT_API_KEY"

Delete Work

curl -X DELETE https://api.pigment.dev/v1/works/work_123 \
  -H "Authorization: Bearer $PIGMENT_API_KEY"

Generate with Prompt

curl -X POST https://api.pigment.dev/v1/prompt \
  -H "Authorization: Bearer $PIGMENT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "abstract geometric pattern with symmetry",
    "iterations": 500
  }'

Kinship Comparison

curl -X POST https://api.pigment.dev/v1/kinship/compare \
  -H "Authorization: Bearer $PIGMENT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "work_ids": ["work_123", "work_456", "work_789"]
  }'

Get Lineage

curl -X GET "https://api.pigment.dev/v1/kinship/work_123/lineage?generations=3" \
  -H "Authorization: Bearer $PIGMENT_API_KEY"

Gallery Listing

curl -X GET "https://api.pigment.dev/v1/gallery?sort=popular&limit=20" \
  -H "Authorization: Bearer $PIGMENT_API_KEY"

Upload to Gallery

curl -X POST https://api.pigment.dev/v1/gallery \
  -H "Authorization: Bearer $PIGMENT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_123",
    "title": "My Masterpiece",
    "tags": ["abstract", "featured"]
  }'

Like Work

curl -X POST https://api.pigment.dev/v1/gallery/gallery_123/like \
  -H "Authorization: Bearer $PIGMENT_API_KEY"
