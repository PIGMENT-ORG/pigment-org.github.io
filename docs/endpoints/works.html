/v1/works

List, retrieve, and manage your generated artworks.

List Works

GET /v1/works

Parameters

ParameterTypeDescription
limitintegerMax items (1-100, default 20)
offsetintegerPagination offset
sortstringSort by: created_at, fitness

Response

{
    "data": [
        {
            "id": "work_123",
            "url": "https://storage.pigment.dev/work_123.png",
            "fitness": 98.5,
            "created_at": "2026-03-15T10:30:00Z",
            "generations": 1000,
            "polygons": 150,
            "tags": ["abstract", "portrait"]
        }
    ],
    "total": 42,
    "limit": 20,
    "offset": 0
}

Delete Work

DELETE /v1/works/{id}

Returns 204 No Content on success.

{
