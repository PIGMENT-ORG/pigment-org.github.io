Works API

Create, retrieve, and manage your generated artworks. Each work is stored as a .pg genome file with associated metadata and 16-dimensional feature vectors.

🧬 What is a .pg file? A PIGMENT Genome file contains the complete description of an artwork: polygons, colors, opacities, and evolution metadata. It's the source code of your art.

Create Work

Create a new artwork by submitting a .pg genome.

POST /v1/works

Request Body

Parameter Type Required Description
title string No Title of the artwork (default: "Untitled")
content string Yes The .pg genome content
type string No Always "pg" for now
parent_id string No ID of parent work (if this is an evolution child)
tags array No List of tags for categorization
generation integer No Generation number (default: 0)

Example Request

curl -X POST https://pigment-api.onrender.com/v1/works \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My First Artwork",
    "content": "-- PIGMENT Genome v6.0.0\n-- @fitness 0.0\n\ncanvas { width: 400 height: 400 }\n\npalette { color_0: #ff3366 }\n\nlayer base {\n  zone poly_0 {\n    color: palette.color_0\n    opacity: 0.8\n    points: 120,140 180,120 160,200\n  }\n}",
    "tags": ["triangle", "demo"]
  }'

Response

{
  "id": "work_2a7f8c3e1b9d4f6",
  "title": "My First Artwork",
  "style": "custom",
  "fitness": 0.0,
  "features": [
    0.5, 0.3, 0.7,  # RGB means
    0.2, 0.1, 0.3,  # RGB stds
    0.4,            # Luminance contrast
    0.6,            # Color entropy
    0.02,           # Polygon count (normalized)
    0.8,            # Avg opacity
    0.3,            # Avg points per polygon
    0.5,            # Hue spread
    0.1,            # Glitch factor
    0.2,            # Organic factor
    0.1,            # Void factor
    0.0             # Fitness proxy
  ],
  "tags": ["triangle", "demo"],
  "created_at": "2026-02-21T12:00:00Z"
}

List Works

Retrieve a paginated list of your artworks.

GET /v1/works

Query Parameters

Parameter Type Description
limit integer Number of items to return (1-100, default 20)
offset integer Number of items to skip (default 0)
style string Filter by style: "glitch", "organic", "void", "custom"

Example Request

curl "https://pigment-api.onrender.com/v1/works?limit=10&offset=0&style=glitch" \
  -H "X-API-Key: your-api-key"

Response

{
  "total": 42,
  "limit": 10,
  "offset": 0,
  "works": [
    {
      "id": "work_2a7f8c3e1b9d4f6",
      "title": "My First Artwork",
      "style": "custom",
      "fitness": 0.0,
      "generation": 0,
      "tags": ["triangle", "demo"],
      "created_at": "2026-02-21T12:00:00Z"
    },
    {
      "id": "work_3b8g9d4f2e1a5c7",
      "title": "Glitch Study #1",
      "style": "glitch",
      "fitness": 78.3,
      "generation": 1542,
      "tags": ["glitch", "abstract"],
      "created_at": "2026-02-21T13:30:00Z"
    }
  ]
}

Note: The content field is omitted in list views for performance. Use GET /v1/works/{id} to retrieve the full genome.

Get Single Work

Retrieve a specific artwork by ID, including its full genome content.

GET /v1/works/{id}

Path Parameters

id string Required Work ID (UUID format)

Example Request

curl https://pigment-api.onrender.com/v1/works/work_2a7f8c3e1b9d4f6 \
  -H "X-API-Key: your-api-key"

Response

{
  "id": "work_2a7f8c3e1b9d4f6",
  "user_id": "user_1b2c3d4e5f6g7h8",
  "title": "My First Artwork",
  "type": "pg",
  "content": "-- PIGMENT Genome v6.0.0\n-- @fitness 0.0\n-- @generation 0\n\ncanvas { width: 400 height: 400 }\n\npalette { color_0: #ff3366 }\n\nlayer base {\n  zone poly_0 {\n    color: palette.color_0\n    opacity: 0.8\n    points: 120,140 180,120 160,200\n  }\n}",
  "features": [0.5, 0.3, 0.7, 0.2, 0.1, 0.3, 0.4, 0.6, 0.02, 0.8, 0.3, 0.5, 0.1, 0.2, 0.1, 0.0],
  "style": "custom",
  "fitness": 0.0,
  "generation": 0,
  "parent_id": null,
  "tags": ["triangle", "demo"],
  "created_at": "2026-02-21T12:00:00Z",
  "updated_at": "2026-02-21T12:00:00Z"
}

Delete Work

Delete an artwork permanently.

DELETE /v1/works/{id}

Example Request

curl -X DELETE https://pigment-api.onrender.com/v1/works/work_2a7f8c3e1b9d4f6 \
  -H "X-API-Key: your-api-key"

Response

{
  "message": "Deleted",
  "id": "work_2a7f8c3e1b9d4f6"
}

Feature Vector Details

Each work includes a 16-dimensional feature vector used for kinship calculations:

Index Feature Description
0-2RGB meansAverage red, green, blue values (0-1)
3-5RGB stdsStandard deviation of each channel
6Luminance contrastSpread of brightness values
7Color entropyComplexity/randomness of colors
8Polygon countNormalized (0-1) polygon count
9Avg opacityAverage opacity across polygons
10Avg pointsAverage points per polygon
11Hue spreadDiversity of hues
12Glitch factorChannel imbalance (0-1)
13Organic factorGreen bias + smoothness
14Void factorDarkness + low complexity
15Fitness proxyNormalized fitness from genome

Error Responses

Code Description
400Invalid parameters or malformed genome
401Missing or invalid API key
403Not authorized to access this work
404Work not found
