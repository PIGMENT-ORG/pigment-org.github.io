Evolve API

Apply genetic algorithm mutations to an existing artwork to create a new evolved version.

📌 Deployment Note: PIGMENT v6 has two deployment modes:
  • Layer 2 (server.py) — Synchronous: returns result immediately
  • Layer 3/4 (FastAPI) — Asynchronous: returns job_id, poll for result

Your current deployment at https://pigment-api.onrender.com uses Layer 2 (synchronous).

Start Evolution

Evolve an existing artwork by applying genetic mutations.

POST /v1/evolve

Request Body

Parameter Type Required Description
work_id string Yes ID of the artwork to evolve
steps integer No Number of evolution steps (1-2000, default 100)
mutation_rate float No Mutation intensity (0.1-5.0, default 1.0)

Example Request

curl -X POST https://pigment-api.onrender.com/v1/evolve \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_2a7f8c3e1b9d4f6",
    "steps": 500,
    "mutation_rate": 1.5
  }'

Response (Synchronous - Layer 2)

{
  "parent_id": "work_2a7f8c3e1b9d4f6",
  "child_id": "work_3b8g9d4f2e1a5c7",
  "generation": 1,
  "fitness_before": 38.7,
  "fitness_after": 52.3,
  "improvement": 13.6,
  "steps_run": 500,
  "operator": "scale",
  "style": "abstract",
  "genome_preview": "-- PIGMENT Genome v6.0.0\n-- @fitness 52.3\n-- @generation 1..."
}

Response (Asynchronous - Layer 3/4)

{
  "job_id": "job_abc123def456",
  "status": "queued",
  "message": "Evolution job queued — poll GET /v1/jobs/job_abc123def456 for result"
}

Check Job Status (Layer 3/4 Only)

If you're using the FastAPI deployment, evolution jobs run asynchronously. Poll this endpoint for status updates.

Real-time Updates via WebSocket

For real-time evolution progress (Layer 3/4 only), connect to our WebSocket endpoint:

// Connect to WebSocket
const ws = new WebSocket('wss://pigment-api.onrender.com/ws/user_123');

// Send authentication
ws.onopen = () => {
    ws.send(JSON.stringify({
        type: 'auth',
        api_key: 'your-api-key'
    }));
};

// Subscribe to job updates
ws.send(JSON.stringify({
    type: 'subscribe_job',
    job_id: 'job_abc123def456'
}));

// Listen for updates
ws.onmessage = (event) => {
    const data = JSON.parse(event.data);
    
    switch(data.type) {
        case 'evolution_tick':
            console.log(`Step ${data.generation}: ${data.fitness}% fitness`);
            console.log(`Progress: ${Math.round(data.progress * 100)}%`);
            break;
            
        case 'evolution_done':
            console.log('Evolution complete!', data.result);
            break;
            
        case 'error':
            console.error('Job error:', data.error);
            break;
    }
};

Evolution Parameters Explained

Steps

The number of mutation attempts to perform. More steps = more evolved but slower. Recommended ranges:

  • 100-500: Quick experiments
  • 500-1000: Balanced evolution
  • 1000-2000: Deep refinement

Mutation Rate

Controls how aggressive mutations are:

  • 0.1-0.5: Fine-tuning, small changes
  • 0.5-1.5: Balanced (default)
  • 1.5-3.0: Exploration, large jumps
  • 3.0-5.0: Chaos mode (glitchy effects)

Mutation Operators

The system selects from these operators based on success history:

Operator Description
scaleResize polygons relative to their center
translateMove polygons in x/y direction
colorShift RGB values of a polygon
opacityChange polygon transparency
rotateRotate polygon around its center
addpointAdd a vertex to increase complexity
intelligentUse best-performing operator

Error Responses

Code Description
400Missing work_id or invalid parameters
401Missing or invalid API key
403Not authorized to evolve this work
404Work not found
429Rate limit exceeded

Complete Example Workflow

// 1. Create a work
const work = await fetch('https://pigment-api.onrender.com/v1/works', {
    method: 'POST',
    headers: { 'X-API-Key': 'your-key' },
    body: JSON.stringify({
        title: 'My Art',
        content: '-- PIGMENT Genome...'
    })
}).then(r => r.json());

// 2. Evolve it (synchronous)
const evolved = await fetch('https://pigment-api.onrender.com/v1/evolve', {
    method: 'POST',
    headers: { 'X-API-Key': 'your-key' },
    body: JSON.stringify({
        work_id: work.id,
        steps: 1000,
        mutation_rate: 1.2
    })
}).then(r => r.json());

console.log(`Fitness improved: ${evolved.fitness_before}% → ${evolved.fitness_after}%`);
console.log(`Best operator: ${evolved.operator}`);
