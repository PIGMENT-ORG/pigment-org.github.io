/v1/evolve

Start an evolution job to generate artwork from a target image.

Start Evolution

POST /v1/evolve

Request Body

ParameterTypeRequiredDescription
target_urlstringYes*Publicly accessible image URL
target_imagestringYes*Base64 encoded image
generationsintegerNoNumber of generations (100-10000, default 1000)
polygonsintegerNoNumber of polygons (10-500, default 100)
mutation_ratefloatNoMutation rate (0.01-1.0, default 0.1)
strategystringNoEvolution strategy
webhook_urlstringNoURL to notify when complete

* Either target_url or target_image is required.

Example Request

curl -X POST https://api.pigment.dev/v1/evolve \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "target_url": "https://images.unsplash.com/photo-1500462918059-b1a0cb512f1d",
    "generations": 1000,
    "polygons": 150,
    "mutation_rate": 0.15
  }'

Response

{
    "job_id": "job_abc123",
    "estimated_seconds": 45,
    "status": "processing"
}

Check Job Status

GET /v1/jobs/{job_id}

WebSocket Real-time Updates

Connect to wss://api.pigment.dev/v1/ws with your API key:

const ws = new WebSocket('wss://api.pigment.dev/v1/ws?token=YOUR_API_KEY');

ws.onmessage = (event) => {
    const update = JSON.parse(event.data);
    console.log(`Progress: ${update.progress}%`);
    console.log(`Current fitness: ${update.fitness}%`);
};
