Kinship API

Discover how your artworks are related. The kinship system builds family trees showing parents, children, siblings, and similar works based on 16-dimensional feature similarity.

🔍 How it works: Each artwork has a 16-dimensional feature vector. Kinship calculates similarity using a weighted combination of visual features (40%), generational distance (30%), and structural properties (30%).

Get Kinship Relationships

Find all relatives of a specific artwork.

POST /v1/kinship

Request Body

Parameter Type Required Description
work_id string Yes ID of the artwork to find relatives for

Example Request

curl -X POST https://pigment-api.onrender.com/v1/kinship \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_2a7f8c3e1b9d4f6"

Search Similar Works

Find works similar to a given work or feature vector.

POST /v1/search/similar

Request Body

Parameter Type Description
work_id string ID of artwork to compare against (optional)
features array 16-dim feature vector (optional, alternative to work_id)
limit integer Max results (default 10)

Example Request

curl -X POST https://pigment-api.onrender.com/v1/search/similar \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_2a7f8c3e1b9d4f6",
    "limit": 5
  }'

Response

{
  "query": "work_2a7f8c3e1b9d4f6",
  "total_searched": 42,
  "results": [
    {
      "id": "work_3b8g9d4f2e1a5c7",
      "title": "Abstract Study #1 (gen 43)",

      "title": "Abstract Study #2",

}

Similarity Calculation

The combined similarity score is a weighted average of three components:

40%
Visual Features
RGB, entropy, texture
30%
Generational
Parent/child distance
30%
Structural
Polygon count, opacity

Relationship Thresholds

Relationship Similarity Threshold Description
Parent/Child ≥ 90% Direct lineage (determined by parent_id)
Sibling ≥ 82% Share the same parent
Cousin 65-81% Share grandparents or great-grandparents
Similar 45-64% Visually similar but no direct lineage

16-Dimensional Feature Vectors

Each artwork's visual characteristics are captured in a 16D vector:

Index Feature Description
0R MeanAverage red channel (0-1)
1G MeanAverage green channel (0-1)
2B MeanAverage blue channel (0-1)
3R StdRed standard deviation
4G StdGreen standard deviation
5B StdBlue standard deviation
6Luminance ContrastSpread of brightness values
7Color EntropyComplexity/randomness of colors
8Polygon CountNormalized (0-1) polygon count
9Avg OpacityAverage opacity across polygons
10Avg PointsAverage points per polygon
11Hue SpreadDiversity of hues present
12Glitch FactorChannel imbalance (0-1)
13Organic FactorGreen bias + smoothness
14Void FactorDarkness + low complexity
15Fitness ProxyNormalized fitness from genome

Visualization

Use our JavaScript library to visualize kinship trees:

// Include the library
<script src="https://pigment-org.github.io/js/kinship-viz.js"></script>

// Create a container
<div id="kinship-tree" style="width: 100%; height: 400px;"></div>

// Fetch and render
const response = await fetch('https://pigment-api.onrender.com/v1/kinship', {
    method: 'POST',
    headers: { 'X-API-Key': 'your-key' },
    body: JSON.stringify({ work_id: 'work_123' })
});

const data = await response.json();
KinshipViz.render('kinship-tree', data);

Code Description

401Invalid or missing API key
403Not authorized to view this work's kinship
404Work not found
422Insufficient data (need at least 2 works)
