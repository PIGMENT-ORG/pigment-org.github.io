/v1/kinship

Analyze relationships between artworks and build family trees.

Compare Works

POST /v1/kinship/compare

Request Body

{
    "work_ids": ["work_123", "work_456", "work_789"],
    "include_features": true,
    "min_similarity": 0.5
}

Response

{
    "matrix": [
        [1.0, 0.85, 0.32],
        [0.85, 1.0, 0.28],
        [0.32, 0.28, 1.0]
    ],
    "features": [
        [0.12, 0.45, 0.67, ...],
        [0.15, 0.42, 0.71, ...],
        [0.98, 0.12, 0.33, ...]
    ]
}

Get Lineage

GET /v1/kinship/{work_id}/lineage

Parameters

generationsintegerNumber of generations to include (1-10, default 3)

Response

{
    "work_id": "work_123",
    "ancestors": [
        {
            "id": "work_122",
            "similarity": 0.92,
            "generation": 1
        },
        {
            "id": "work_121",
            "similarity": 0.78,
            "generation": 2
        }
    ],
    "descendants": [
        {
            "id": "work_124",
            "similarity": 0.88,
            "generation": 1
        }
    ],
    "tree": {
        "id": "work_121",
        "children": [
            {
                "id": "work_122",
                "children": [
                    {"id": "work_123"}
                ]
            }
        ]
    }
}

Find Relatives

GET /v1/kinship/{work_id}/relatives

Parameters

thresholdfloatSimilarity threshold (0-1, default 0.7)

Response

{
    "work_id": "work_123",
    "relatives": [
        {
            "id": "work_456",
            "similarity": 0.89,
            "relationship": "sibling"
        },
        {
            "id": "work_789",
            "similarity": 0.76,
            "relationship": "cousin"
        }
    ]
}

Feature Vectors

Each artwork is represented by a 16-dimensional feature vector:

  • Dimensions 1-4: Color distribution
  • Dimensions 5-8: Shape complexity
  • Dimensions 9-12: Texture patterns
  • Dimensions 13-16: Composition metrics
