POST /v1/kinship

Kinship Endpoint

Discover how your artworks are related. The kinship system builds family trees showing parents, children, siblings, and similar works based on feature similarity.

🔍 How it works: Each artwork has a 16-dimensional feature vector. Kinship calculates similarity using a weighted combination of visual features, generational distance, and structural properties.

Request

Body Parameters

Parameter Type Required Description
work_id string Yes ID of the artwork to find relatives for

Example Request

cURL 
curl -X POST https://pigment-api.onrender.com/v1/kinship \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_abc123"
  }'

Response

Response Fields

Field Type Description
work object The source artwork details
parents array Direct ancestors (similarity ≥ 0.90)
children array Direct descendants
siblings array Works with same parent (similarity ≥ 0.82)
cousins array Similar works (similarity 0.65 - 0.81)
similar array Related works (similarity 0.45 - 0.64)
total_relationships integer Total count of all relatives found

Relationship Types

Parent/Child

Direct lineage relationship. Child works are evolved from parents.

similarity ≥ 90%
Sibling

Share the same parent work.

similarity ≥ 82%
Cousin

Share grandparents or great-grandparents.

similarity 65-81%
Similar

Visually similar but no direct lineage.

similarity 45-64%

Similarity Calculation

The combined similarity score is weighted from three components:

40%
Visual Features
RGB, entropy, texture
30%
Generational
Parent/child distance
30%
Structural
Polygon count, opacity

Visualization

Use our JavaScript library to visualize kinship trees:

import { KinshipViz } from 'https://pigment-org.github.io/js/kinship-viz.js';

// Fetch kinship data
const response = await fetch('https://pigment-api.onrender.com/v1/kinship', {
  method: 'POST',
  headers: { 'X-API-Key': 'your-key' },
  body: JSON.stringify({ work_id: 'work_abc123' })
});

const data = await response.json();

// Render interactive tree
const viz = KinshipViz.create('viz-container', data);
viz.render();
