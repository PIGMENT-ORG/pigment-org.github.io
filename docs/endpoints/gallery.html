/v1/gallery

Public gallery of generated artwork from the PIGMENT community.

List Gallery

GET /v1/gallery

Parameters

ParameterTypeDescription
limitintegerItems per page (1-50)
offsetintegerPagination offset
sortstringSort by: latest, popular, fitness
tagsstringComma-separated tags to filter

Response

{
    "data": [
        {
            "id": "work_123",
            "thumbnail": "https://storage.pigment.dev/thumb_123.jpg",
            "title": "Neon Dreams",
            "author": "user_456",
            "fitness": 98.5,
            "likes": 42,
            "created_at": "2026-03-15T10:30:00Z",
            "tags": ["abstract", "featured"]
        }
    ],
    "total": 1523,
    "limit": 20,
    "offset": 0
}

Upload to Gallery

POST /v1/gallery

Request Body

{
    "work_id": "work_123",
    "title": "My Masterpiece",
    "description": "Generated with PIGMENT v6",
    "tags": ["abstract", "portrait"],
    "public": true
}

Response

{
    "id": "gallery_123",
    "url": "https://pigment.dev/gallery/123",
    "status": "published"
}

Like/Unlike

POST /v1/gallery/{id}/like

DELETE /v1/gallery/{id}/like
