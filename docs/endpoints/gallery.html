GET /v1/gallery

Gallery API

Browse public artworks from the PIGMENT community. The gallery shows all works ordered by fitness score, with pagination and style statistics.

📌 Note: The gallery shows all public works across all users. Each work includes its fitness score, generation count, style classification, and tags — not images, since PIGMENT stores genome data rather than rendered images.

List Gallery

Retrieve a paginated list of public artworks, sorted by fitness (highest first).

GET /v1/gallery

Query Parameters

Parameter Type Description
limit integer Number of items to return (1-100, default 24)
offset integer Number of items to skip (default 0)

Example Request

curl "https://pigment-api.onrender.com/v1/gallery?limit=10&offset=0" \
  -H "X-API-Key: your-api-key"

Get Gallery Stats

The gallery response includes aggregated statistics about all public works:

Stat Description
total Total number of public works in the gallery
stats.{style}.count Number of works with this style classification
stats.{style}.avg_fitness Average fitness score for works of this style

Get Single Gallery Item

Retrieve detailed information about a specific public artwork.

GET /v1/works/{id}

Gallery items are just works — use the same /v1/works/{id} endpoint with your API key.

Example Request

curl https://pigment-api.onrender.com/v1/works/work_2a7f8c3e1b9d4f6 \
  -H "X-API-Key: your-api-key"

Response (abbreviated)

{
  "id": "work_2a7f8c3e1b9d4f6",
  "title": "Neon Dreams",
  "style": "glitch",
  "fitness": 98.5,
  "generation": 1542,
  "tags": ["abstract", "featured", "cyberpunk"],
  "features": [0.8, 0.3, 0.9, ...],
  "created_at": "2026-02-21T12:00:00Z",
  "parent_id": "work_1a2b3c4d5e6f7g8"
}

Style Statistics

The gallery provides insights into how different styles perform:

Style Description Typical Fitness Range
glitch High channel imbalance, chaotic colors 75-95%
organic Green bias, smooth transitions 70-90%
void Dark, high opacity, low complexity 65-85%
custom Mixed or undefined style 60-80%

Integration with Other Endpoints

Once you find an interesting work in the gallery, you can:

  • Get its full details with GET /v1/works/{id}
  • Find similar works with POST /v1/search/similar
  • Explore its family tree with POST /v1/kinship
  • Trace its ancestry with GET /v1/ancestry/{id}

Example: Find Similar to Gallery Work

# First, get a work ID from the gallery
curl "https://pigment-api.onrender.com/v1/gallery?limit=1"

# Then search for similar works
curl -X POST https://pigment-api.onrender.com/v1/search/similar \
  -H "X-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_2a7f8c3e1b9d4f6",
    "limit": 5
  }'

Error Responses

Code Description
401Missing or invalid API key
400Invalid pagination parameters (limit > 100)
