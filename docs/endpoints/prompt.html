POST /v1/prompt

AI Prompt API

Guide the evolution process using natural language. Describe what you want to see, and our AI (Claude) translates your words into specific mutation operations.

🤖 How it works:
  • Claude API When available, Claude analyzes your prompt and returns a structured mutation plan
  • Keyword Fallback If Claude is unavailable, intelligent keyword matching is used

The system learns from every prompt to improve future generations.

Apply AI Prompt to Artwork

Evolve an existing artwork using natural language guidance.

POST /v1/prompt

Request Body

Parameter Type Required Description
work_id string Yes ID of the artwork to evolve
prompt string Yes Natural language description of desired changes (max 500 chars)

Example Request

curl -X POST https://pigment-api.onrender.com/v1/prompt \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_2a7f8c3e1b9d4f6",
    "prompt": "make it glitchy with more contrast and neon colors"
  }'

Response

{
  "parent_id": "work_2a7f8c3e1b9d4f6",
  "child_id": "work_3b8g9d4f2e1a5c7",
  "intent": "Apply digital glitch aesthetic with enhanced contrast and neon color palette",
  "operations_applied": [
    "glitch_colors",
    "boost_contrast",
    "saturate",
    "chaos"
  ],
  "used_claude": true,
  "fitness_before": 72.4,
  "fitness_after": 68.9,
  "improvement": -3.5,
  "style": "glitch"
}

How Prompt Processing Works

1. Prompt Analysis

Your prompt is sent to Claude API (or local keyword matcher) which analyzes intent and generates a structured mutation plan.

2. Mutation Plan

The AI returns a JSON plan like:

{
  "intent": "Apply glitch aesthetic",
  "operations": [
    {"op": "glitch_colors", "intensity": 0.8},
    {"op": "chaos", "intensity": 0.4},
    {"op": "boost_contrast", "intensity": 0.6}
  ],
  "mutation_rate_multiplier": 3.0
}

3. Execution

The plan is applied to the artwork's genome, creating a new evolved version.

4. Learning

All prompts and results are logged to improve future AI responses.

Supported Mutation Operations

The AI can trigger any of these operations based on your prompt:

Local Fallback Keywords

When Claude API is unavailable, the system uses intelligent keyword matching:

Keywords Effect
glitch, corrupt, noise, digital error glitch_colors + chaos + boost_contrast (mut_rate 3.0×)
organic, nature, smooth, growth, calm organic_spread + smooth + saturate (mut_rate 0.5×)
void, dark, black, empty, shadow void_crush + darken + remove_polygons (mut_rate 0.6×)
bright, vivid, pop, vibrant, neon lighten + saturate + boost_contrast (mut_rate 1.2×)
minimal, simple, clean, few remove_polygons + desaturate + smooth (mut_rate 0.3×)
complex, detailed, intricate, busy add_polygons + boost_contrast (mut_rate 1.5×)
warm, hot, fire shift_palette (red/orange) + saturate (mut_rate 1.3×)
cool, cold, blue shift_palette (blue) + desaturate (mut_rate 1.3×)

Best Practices

  • Be specific: "add magenta channel offset with pixel sorting" works better than "make it glitchy"
  • Combine styles: "glitchy but organic" will try to balance both aesthetics
  • Use contrast terms: "more contrast", "brighter", "darker" adjust luminance
  • Reference colors: "neon green", "warm orange", "cool blue" shift the palette
  • Iterate: Apply prompts incrementally for finer control

Complete Example Workflow

// 1. Create or get a work
const work = await fetch('https://pigment-api.onrender.com/v1/works', {
    method: 'POST',
    headers: { 'X-API-Key': 'your-key' },
    body: JSON.stringify({
        title: 'Base Artwork',
        content: '-- PIGMENT Genome...'
    })
}).then(r => r.json());

// 2. Apply AI prompt
const promptResult = await fetch('https://pigment-api.onrender.com/v1/prompt', {
    method: 'POST',
    headers: { 'X-API-Key': 'your-key' },
    body: JSON.stringify({
        work_id: work.id,
        prompt: 'make it glitchy with neon accents'
    })
}).then(r => r.json());

console.log(`AI intent: ${promptResult.intent}`);
console.log(`Operations: ${promptResult.operations_applied.join(', ')}`);
console.log(`Used Claude: ${promptResult.used_claude}`);

// 3. Get the evolved work
const evolved = await fetch(`https://pigment-api.onrender.com/v1/works/${promptResult.child_id}`, {
    headers: { 'X-API-Key': 'your-key' }
}).then(r => r.json());

console.log(`New fitness: ${evolved.fitness}%`);
console.log(`Style: ${evolved.style}`);

Error Responses

Code Description
400Missing work_id or prompt, or prompt too long (>500 chars)
401Invalid or missing API key
403Not authorized to evolve this work
404Work not found
429Rate limit exceeded (60/min free tier)
503Claude API unavailable (fallback used, check response)
