POST /v1/prompt

AI Prompt Endpoint

Guide the evolution process using natural language. Describe what you want to see, and our AI (Claude) translates your words into specific mutation operations.

🤖 AI Integration: This endpoint uses Anthropic's Claude API when available, with a smart fallback to keyword-based matching. The system learns from every prompt to improve future generations.

Request

Body Parameters

Parameter Type Required Description
work_id string Yes ID of the artwork to evolve
prompt string Yes Natural language description of desired changes

Example Request

cURL 
curl -X POST https://pigment-api.onrender.com/v1/prompt \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "work_id": "work_abc123",
    "prompt": "make it glitchy with more contrast and neon colors"
  }'

Response

Response Fields

Field Type Description
parent_id string ID of the original artwork
child_id string ID of the newly evolved artwork
intent string AI's interpretation of your prompt
operations_applied array List of mutation operations performed
used_claude boolean Whether Claude API was used (vs local fallback)
fitness_before float Fitness score before evolution
fitness_after float Fitness score after evolution
style string Detected style of the new artwork

Example Response

{
  "parent_id": "work_abc123",
  "child_id": "work_def456",
  "intent": "Apply digital glitch aesthetic with enhanced contrast and neon color palette",
  "operations_applied": [
    "glitch_colors",
    "boost_contrast",
    "saturate",
    "chaos"
  ],
  "used_claude": true,
  "fitness_before": 72.4,
  "fitness_after": 68.9,
  "improvement": -3.5,
  "style": "glitch"
}

Supported Operations

The AI can trigger any of these mutation operations based on your prompt:

shift_palette boost_contrast darken lighten chaos smooth saturate desaturate scale_polygons rotate_all add_polygons remove_polygons set_opacity glitch_colors organic_spread void_crush

Example Prompts

"make it glitchy, more contrast"
Operations: glitch_colors, chaos, boost_contrast
mut_rate: 3.0×
"give it an organic, nature feel"
Operations: organic_spread, smooth, saturate
mut_rate: 0.5×
"darker, more void-like"
Operations: void_crush, darken, remove_polygons
mut_rate: 0.6×
"add more detail and complexity"
Operations: add_polygons, boost_contrast
mut_rate: 1.5×

How It Works

1. Prompt Analysis

Your prompt is sent to Claude API (or local keyword matcher) which analyzes intent and generates a structured mutation plan.

2. Mutation Plan

The AI returns a JSON plan like:

{
  "intent": "Apply glitch aesthetic",
  "operations": [
    {"op": "glitch_colors", "intensity": 0.8},
    {"op": "chaos", "intensity": 0.4},
    {"op": "boost_contrast", "intensity": 0.6}
  ],
  "mutation_rate_multiplier": 3.0
}

3. Execution

The plan is applied to the artwork's genome, creating a new evolved version.

4. Learning

All prompts and results are logged to improve future AI responses.

Local Fallback Keywords

When Claude API is unavailable, the system uses keyword matching:

Keyword Effect
glitch, corrupt, noise glitch_colors + chaos + boost_contrast (mut_rate 3.0×)
organic, nature, smooth organic_spread + smooth + saturate (mut_rate 0.5×)
void, dark, black void_crush + darken + remove_polygons (mut_rate 0.6×)
bright, vivid, pop lighten + saturate + boost_contrast (mut_rate 1.2×)
minimal, simple remove_polygons + desaturate + smooth (mut_rate 0.3×)
neon, electric saturate + lighten + glitch_colors (mut_rate 1.8×)

Best Practices

  • Be specific: "make it glitchy" works, but "add magenta channel offset with pixel sorting" gives better results
  • Combine styles: "glitchy but organic" will try to balance both
  • Use contrast terms: "more contrast", "brighter", "darker" adjust luminance
  • Reference colors: "neon green", "warm orange", "cool blue" shift the palette

Error Responses

Code Description
400 Missing work_id or prompt
401 Invalid API key
404 Work not found
429 Rate limit exceeded (60/min free tier)
503 Claude API unavailable (fallback used)
