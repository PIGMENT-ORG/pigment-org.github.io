/v1/prompt

Generate artwork using natural language prompts with AI guidance.

Generate from Prompt

POST /v1/prompt

Request Body

ParameterTypeDescription
promptstringText description of desired artwork
stylestringStyle guide (abstract, realistic, geometric)
iterationsintegerNumber of evolution iterations
seedintegerRandom seed for reproducibility
guidance_scalefloatHow closely to follow prompt (0-2, default 1.0)

Example Request

curl -X POST https://api.pigment.dev/v1/prompt \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "a cyberpunk cityscape with neon lights reflecting on wet streets",
    "style": "geometric",
    "iterations": 500,
    "guidance_scale": 1.2
  }'

Response

{
    "job_id": "job_abc123",
    "prompt": "a cyberpunk cityscape...",
    "estimated_seconds": 30
}

Style Transfer

POST /v1/prompt/style-transfer

Request Body

{
    "content_image": "base64_encoded_image",
    "style_image": "base64_encoded_image",
    "strength": 0.7
}

Response

{
    "work_id": "work_123",
    "image_url": "https://storage.pigment.dev/result.png",
    "style_strength": 0.7
}
